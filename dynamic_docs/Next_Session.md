## This session's work, for context

- **Summary Stat Tags — new feature, built and iterated live across many small corrections.** Second table on the Text tab ("Statistic text replacement tags"): short, permanent, base-36 tag ids (`[3]`, `[a7]`) each standing in for one summary-stats value from one chart's own independently-authored cut of its cached data (`hex_id`, a single population token, TimeSeries-only period/metric fields, a Reference id). New storage: `workfile_config/text_stats.csv`. See Architecture Decision 19, Functional Spec §12.1, Feature List's new row.
  - Several real bugs surfaced through live testing and were fixed in place — worth reading Architecture Decision 19 and Current_State's "Resolved this session" list in full before touching this feature again, since the fixes encode real lessons: (1) a token like `Region()` must be re-resolved fresh every time against the current reporting unit, never frozen to the value it happened to resolve to at creation; (2) a "keep only what's currently valid" filter on a Streamlit multiselect must not destroy something only *momentarily* invalid mid-reconfiguration — use a persisted record, reconciled against what was actually offered, not overwritten wholesale; (3) never write to a widget's own session-state key on every render regardless of circumstance — Streamlit already commits a fresh interaction before the script reruns, so an unconditional overwrite silently discards it.
