### What works (built/changed this session)

- **`chart_type_ref` renamed to `base_chart_name` everywhere, including the on-disk Running Order column.** Mechanical rename across 12 code files (running_order module, `assembly_engine.py`, `chart_type_map.py`/`.csv`, `base_charts/registry.py` and its four shape `__init__.py` files, `custom_charts/bundle.py`/`resolve.py`/`__init__.py`, `charts_tab.py`, `outputs_tab.py`, `running_order_tab.py`, `workfile_file.py`) plus all four governed docs (Architecture, Functional Spec, Feature List, Glossary). `table_type_ref` (tables) was untouched throughout -- a different identifier, not part of this rename. Confirmed via full-codebase search: no stray `chart_type_ref` references remain anywhere.
  - **File version bumped.** `version_compatibility.csv`: `file_version_written`/`file_versions_readable` moved from `0.0.3` to `0.0.4`, with `0.0.3` dropped from the readable list entirely -- a workfile saved before this rename will not open (Decisions.md: accepted as a breaking change, no live workfiles existed at the time so no migration was needed).
- **Output Table generation simplified -- fixed size, no-name yellow box, auto-naming, no re-upload matching.**
  - **Every Output Table starts at 7 rows x 4 columns** (`grid_store.DEFAULT_TABLE_ROWS`/`DEFAULT_TABLE_COLUMNS`), whether created via a yellow box or the Output Tables tab's own "+ New Output Table" form -- no user-configurable Rows/Columns at creation time either way.
  - **Yellow box syntax simplified to the literal word `Table`** (case/whitespace-insensitive, `TABLE_BOX_RE` in `template_reader.py`) -- no `:name`, no `Rows:`/`Columns:`. `PlaceholderInfo.table_name`/`table_rows`/`table_columns` replaced with a single `table_id` field, filled in downstream.
  - **Every yellow-box `Table` occurrence always creates a brand-new Output Table, never matched against an existing one.** `import_flow.merge_output_tables_from_template` rewritten: no more by-name dedup/"already_present" tracking -- every occurrence gets a fresh table, auto-named `Table_1`, `Table_2`, ... (underscore, guaranteed unique against existing names), with `table_id` set directly on the placeholder. Re-uploading the same template twice now produces two independent sets of tables, not one reused set -- the user re-links Running Order rows to whichever set they want. `generate_from_template` reads `ph.table_id` straight off the placeholder now, not a name lookup; the `output_tables_by_name` parameter/plumbing is gone entirely, including the now-obsolete `output_tables_already_present` return key.
  - **Manual "+ New Output Table" form simplified to Name only** (`output_tables_tab.py`) -- Rows/Columns inputs dropped, uses the fixed defaults.
  - **Manually-created tables now get automatic Running Order placement too.** New helper, `row_ops.append_content_row_above_footer`, builds a fresh row and inserts it immediately above the first `save_ppt` row (end of the per-report content section, before the footer/batch-close rows). Creating a table via the form now appends an `insert_table` row automatically -- blank `slide_index`/position, width/height defaulted to 70%/50% of page (`percent_to_emu`/`get_page_size_emu`, falling back to the standard-size default if no template page size is known yet). A blank `slide_index` is not a validation blocker -- `insert_table` already errors gracefully per-row at run time if it's still unset (existing behaviour, confirmed, not a new risk).
  - **Bug fixed during testing:** `_render_new_table_form`'s success branch originally wrote directly to `st.session_state["ot_table_choice"]` after that widget had already been instantiated earlier in the same run -- raised `StreamlitAPIException`. Fixed by staging the new name through the existing `"ot_pending_table_choice"` pattern (already used elsewhere in this file for the same reason), applied before the selectbox's next instantiation.
- **Architecture, Functional Spec, and Feature List updated in the mirror.** Architecture: `base_chart_name` rename throughout, `table_name` schema-row description rewritten, Decision 23's identity paragraph rewritten (fixed size, auto-naming, no re-upload matching, automatic placement for manual tables).
